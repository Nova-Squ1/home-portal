邮箱

支持多个邮箱 IMAP 聚合（QQ / Gmail / 自建邮箱等）。凭证文件： config/mail.yml
从 mail.yml.example 复制并填入授权码即可，无需重启，5 分钟内生效。

工作台 2.0

Edge 翻译插件

用 Codex 订阅的 gpt-5.6-luna 翻译网页：点插件图标或按 Alt+T 翻译 / 还原，弹窗里可切原地替换或双语对照。
安装：下载并解压 → Edge 打开 edge://extensions，开「开发人员模式」→「加载解压缩的扩展」选 codex-translate 文件夹 → 点插件图标，填本门户地址并保存。
Edge 自带的翻译提示要在 edge://settings/languages 里关掉「提供翻译」。翻译报错说 Codex 调用失败时，在服务器上跑一次 codex 续期令牌。
